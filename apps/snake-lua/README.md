# Snake (Lua)

The Lua version of the SolarOS Snake example. The board scales to the available
graphic display and uses simple tones for game feedback.

Controls:

- Arrow keys, WASD, or HJKL move.
- Space or P pauses and resumes.
- Enter, R, or Space restarts after a collision.
- Escape or Q exits.

Requires a graphic display and audio output.
